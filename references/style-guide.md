# 北大系列画风

## 人物概括

从主照保留 3–5 项辨识特征，分别记录脸部结构、眼睛与神态、衣着和姿势。按[面部结构指南](face-structure.md)确认头部倾斜、颊宽与下颌走向。头可统一等比放大，眼睛仍保留本人的开口长宽、眼睑遮盖、视线和左右差异。眉头张力与嘴角分别观察，闭口与露齿按本人照表现。

## 线条与上色

参考[人物画法示意](../assets/portrait-style.png)的线重和笔触。面部内线略轻，发顶、下颌与肩袖外沿稍重，有笔压变化和收笔。肩线、袖缘、侧缝与翻领用连贯长线。头发用几块色形和少量走向线，眼镜保留框形和倾斜，牙齿合成一块白形，胡须只用必要短线。

衣服先确认底色和花纹色，再用宽马克笔平涂、轻微叠色和少量纸白。肤色遵循本人肤色的明暗关系，浅肤色亮面可用暖象牙色，发际、鼻侧与下颌用稀疏浅赭色块。保留额头和面颊的大块亮区。眉眼鼻口与衣服使用一致的笔触语言，避免成团腮红、细密渐变、亮塑料反光或逐根发丝。

## 对照顺序

1. 先看缩图中的人物轮廓、头身比例和景物主次。
2. 再看面部倾斜、下巴、眼神和辨识特征。改色或改关键词时沿用认可人像。
3. 检查衣服平涂、纸白和轮廓的连续性。
4. 核对景物轮廓、文字拼写、姓名条和裁切边距。
